# 교안 템플릿 슬라이드 스타일 가이드

`교안 템플릿.pptx` 에서 추출한 디자인 시스템 정리본.
한 줄 요약: **파스텔 + 굵은 검정 외곽선 + 레트로 브라우저 창 + 모눈종이 배경**의 키치·귀여운 교육용 스타일.

|---|---|

| 배경 패턴 | 옅은 핑크 모눈종이 그리드 (`#F5DBDC` 계열, 얇은 선) |

| 이름 | HEX | 성격 |
|---|---|---|
| 코랄 핑크 | `#FC999F` | 메인 강조 (타이틀 슬라이드 배경) |
| 라벤더 퍼플 | `#D6BDF7` | 보조 강조 |

> **운용 규칙**: 슬라이드 1장당 메인 포인트색 1개만 사용. 소제목 슬라이드를 색깔별로 돌려쓰면 챕터 구분 효과가 난다 (오렌지 → 핑크 → 퍼플 → 민트…).

## 3. 타이포그래피

| 역할 | 폰트 | 특징 |
|---|---|---|
| 제목 / 강조 | **Paperlogy 7 Bold** | 아주 굵은 고딕, 자간 좁게 |
| 본문 / 설명 | Paperlogy 4 Regular | |

- 대체 폰트: Pretendard Bold / 나눔스퀘어 Bold / 에스코어 드림 8 Heavy
- 제목 색: `#152A20` (검정 대신 딥 그린블랙 — 부드러움)
- 타이틀 슬라이드의 차시명 등 보조 텍스트만 화이트
- 제목은 **가운데 정렬**, 본문 설명도 상단 가운데 정렬

## 4. 핵심 그래픽 모티프

### 4-1. 레트로 브라우저 창 (가장 중요한 요소)
모든 슬라이드의 뼈대. 구성:

- 바깥 사각형: **라운드 코너(약 20~24px)** + `#152A20` 얇은 실선 테두리(2~3px)
- 상단 타이틀바: 크림색(`#FFF8F7`), 아래쪽에 구분선
- 타이틀바 우측: **신호등 원 3개** — 옐로우 `#FAE5A8` / 핑크 `#FC999F` / 민트 `#9CF0E5` (순서 고정)
- 타이틀바 안 또는 창 본문에 제목 배치

### 4-2. 스티커 도형
창 테두리에 **걸쳐서** 배치 (반은 창 안, 반은 밖 → 입체감).
- 종류: ♥ 하트, ★ 별, 웃는 얼굴(눈·미소만 있는 원)
- 모두 파스텔 단색 + `#152A20` 외곽선
- 슬라이드당 1~2개만. 색은 그 슬라이드 메인 컬러와 다른 색으로.

### 4-3. 낙서 선 (doodle line)
얇은 검정 손그림 곡선/루프. 슬라이드 좌측 하단, 우측 중앙 등 여백에 배치해 화면을 잡아준다.

### 4-4. 오브젝트 일러스트 (타이틀 슬라이드 한정)
연필/마커, 마우스, 키보드 등 **파스텔 플랫 일러스트 + 검정 외곽선**. 네 모서리에 흩뿌리듯 배치.

### 4-5. 오프셋 그림자
박스 아래에 같은 모양을 **살짝 아래로 밀어** 다른 색(주로 `#D2FABB`)으로 깔아 두는 이중 레이어. 타이틀 박스에 사용.

## 5. 슬라이드 레이아웃 유형

| # | 레이아웃 | 구성 |
|---|---|---|
| 1 | **타이틀** | 상단 작은 창(연도·과정명 + 신호등) → 큰 코랄 핑크 패널 → 그 안에 버터 옐로우 제목 박스(그린 오프셋 그림자) → 하단 차시명(화이트) |
| 2 | **학습 목표** | 브라우저 창 안에 컬러 카드 3장 가로 배치 (핑크/오렌지/퍼플, 라운드 사각, 텍스트 세로 가운데) |
| 3 | **간지(소제목)** | 창 전체를 포인트색으로 채움 → 중앙에 큰 제목 → 아래 크림색 라운드 바에 설명 한 줄 |
| 4 | **본문** | 창 내부 흰 배경 → 타이틀바에 제목 → 상단 가운데 "설명" → 아래는 콘텐츠 여백 |
| 5 | **마무리** | 민트 창 + "감사합니다" + 크림색 큰 박스(창 밖으로 살짝 넘치게)에 다음 차시명 |

---

## 6. 스타일 재현 체크리스트

- [ ] 배경은 `#FFF8F7` + 옅은 핑크 모눈
- [ ] 모든 도형에 `#152A20` 외곽선, 라운드 코너
- [ ] 그라데이션·드롭섀도우 **금지** (플랫 + 오프셋 그림자만)
- [ ] 신호등 3색 원은 항상 노랑→핑크→민트 순
- [ ] 슬라이드당 포인트색 1개
- [ ] 스티커 도형은 창 테두리에 걸치게
- [ ] 여백에 낙서 선 1개
- [ ] 폰트는 Paperlogy(또는 Pretendard) Bold/Regular 두 단계만

```css
  --bg:        #FFF8F7;
  --grid:      #F5DBDC;
  --ink:       #152A20;
  --white:     #FFFFFF;
  --pink:      #FC999F;
  --purple:    #D6BDF7;
  --orange:    #FFD4A8;
  --yellow:    #FAE5A8;
  --mint:      #9CF0E5;
  --green:     #D2FABB;

  --radius:    24px;
  --border:    2.5px solid var(--ink);
  --font:      "Paperlogy", "Pretendard", sans-serif;
}

body {
  background-color: var(--bg);
  background-image:
    linear-gradient(var(--grid) 1px, transparent 1px),
    linear-gradient(90deg, var(--grid) 1px, transparent 1px);
  background-size: 72px 72px;
}
```
