교실 UX

목차 점프, 발표자 노트, 활동 타이머, 화면 가리기, PDF 내보내기.

교실에서 쓰는 법

  • HTML 파일 하나입니다. 교실 PC에서 더블클릭하면 열립니다 — 설치도 인터넷도 필요 없습니다.
  • F 전체화면 · → 다음 · O 목차 · N 발표자 노트 · B 화면 가리기 · P PDF
  • 활동 슬라이드의 타이머는 눌러서 바로 씁니다. 0이 되면 깜빡입니다.
